# 미니게임 — 캐시플로우 기획 스펙

> 로버트 기요사키의 CASHFLOW 보드게임을 앱 내 미니게임으로 구현.
> 재무 지식을 실전처럼 익히는 금융 교육 콘텐츠.

---

## 게임 모드

| 모드 | 구성 | 시간 | 상태 |
|------|------|------|------|
| 단축버전 | 나 + AI 1명 | 10~15분 | 1차 구현 대상 |
| 풀버전 | 나 + AI 2~3명 | 30~60분 | 2차 구현 |
| 멀티플레이 | 최대 4명 (실제 사용자) | 미정 | 아이디어 (추후) |

---

## 단축버전 상세 스펙

### 난이도

| 난이도 | AI 성격 | 탈출 조건 | 턴 제한 |
|--------|---------|-----------|---------|
| 하 | 안정형 (보수적, 실수 많음) | 수동소득 ≥ 지출 40% | 20턴 |
| 중 | 균형형 | 수동소득 ≥ 지출 60% | 20턴 |
| 상 | 공격형 (레버리지·타이밍 최적화) | 수동소득 ≥ 지출 80% | 20턴 |

- 턴 제한 초과 시 → 수동소득이 가장 높은 플레이어 승리

### 카드 덱

| 카드 종류 | 수량 | 비고 |
|-----------|------|------|
| 소형 딜 (Opportunity) | 15장 | 부동산·주식·사업 투자 |
| 낭비 (Doodad) | 10장 | 충동 지출, 현금 감소 |
| 시장 (Market) | 8장 | 주식·부동산 시세 변동 |
| 대형 딜 | 없음 | 풀버전 전용 |

### 직업 카드

- 게임 시작 시 **랜덤 받기 / 직접 선택** 중 선택
- 단축버전 3종

| 직업 | 특징 |
|------|------|
| 회사원 | 안정적 월급, 중간 지출 |
| 자영업자 | 높은 수입, 높은 지출·부채 |
| 프리랜서 | 낮은 고정 지출, 불규칙 수입 |

## 게임 진행 흐름

```
게임 시작
  → 직업 카드 선택 (랜덤 or 직접)
  → 난이도 선택
  → 재무제표 확인

매 턴
  → 주사위 굴려 이동
  → 칸 종류에 따라 카드 뽑기
  → 투자/지출 여부 결정
  → 현금 흐름 업데이트
  → 수동소득 ≥ 탈출 조건 달성 시 → 탈출 선언

종료 조건
  → 플레이어 탈출 or 20턴 초과 → 게임 종료
  → 결과 화면 + AI 피드백
```

---

## 재무제표 구조

```
수입 계산서
  월급 + 수동소득(부동산·배당·이자) = 총수입

지출 계산서
  세금 + 주거 + 식비 + 교통 + 대출이자 + ... = 총지출

현금 흐름 = 총수입 - 총지출

대차대조표
  자산: 주식, 부동산, 사업 (현금 흐름 발생)
  자산에서 발생하는 현금 흐름 = 수동소득
  부채: 주택담보대출, 자동차 할부, 신용카드
```

## 히스토리 + 피드백

### v1 — 룰 기반 수치 분석

- 게임 종료 후 결과 화면에서 제공
- 최적 탈출 턴 vs 실제 탈출 턴
- 놓친 딜 목록
- DB에 게임 히스토리 저장

### 누적 데이터 (DB)

- 게임별 기록 저장
- 사용자 지표 추적: 평균 탈출 턴, 투자 성향, 승률
- 대시보드에서 내 플레이 통계 확인 가능

### v2 — Claude API 자연어 분석 (추후)

- "3턴에 아파트 딜을 패스했는데, 그때 샀으면 8턴 만에 탈출 가능했어요."
- 별도 API 비용 발생 → v2에서 적용
